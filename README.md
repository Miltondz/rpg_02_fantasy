# rpg_02_fantasy

A new fantasy RPG project based on the original `Miltondz/rpg_01` prototype.

This repository preserves the same browser-game structure and design direction:
- HTML5 + JavaScript front-end
- dungeon exploration and dungeon themes
- party-based mechanics and turn-based combat
- JSON-driven levels, campaigns, and narrative data

## Quick start

Run a local web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project structure

```text
index.html
styles/

levels/
campaigns/
```
